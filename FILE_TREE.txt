TROUBLESHOOTING QUICK REFERENCE
================================

Issue: "Failed to load meta.json"
→ Ensure bundle files exist in chrome_ext/bundle/

Issue: "Bundle mismatch"
→ Rebuild: cd index_build && python main.py

Issue: No results
→ Try broader query: "temperature deviation India"

Issue: Extension won't load
→ Check chrome://extensions/ for error details

Issue: Slow queries (>1s)
→ Check index size, consider FAISS optimization

Issue: Python dependencies fail
→ Use virtual environment: python -m venv venv

Issue: Permission denied (setup.sh)
→ chmod +x setup.sh
